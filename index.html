Sample Answer

A Ready Script

Hi, I'm [Your Name] from [City]. My father, [Name, occupation], and my mother, [Name, occupation]; I have [one sibling / no siblings]. I'm a final-year CS student at [College]. I built [Project] using [Tech], which [result]. I interned at [Company], where I [outcome]. I'm good at [3 skills], and I want to grow as a [target role].
Name Family Education Work Skills Goal
Keep it short and precise. Do not rush — speak calmly and clearly.
Block 1

Name & Basics

DO

  • Full name
  • City
  • Your role in one short line
  • Smile first

DON'T

  • “Myself Rahul”
  • Home address
  • Nicknames
  • Age talk
Say: “Hi, I'm Rahul Sharma from Pune — a final-year CS student.” Short and precise.
Block 2

Family Background

Cover these 4 points. Keep each point short and precise.

COVER THESE 4 POINTS

  • Father — name + occupation
  • Mother — name + occupation
  • Siblings — how many + what they do
  • One short line on values

DON'T SAY

  • Relatives' details
  • Salary, loans, property
  • Family problems
  • Long emotional stories
Practical example “My father, Mr. Rajesh Sharma, runs a textile business. My mother, Mrs. Sunita Sharma, is a homemaker. I have one younger brother studying engineering. My family has always supported my studies and taught me discipline.”
Block 3

Education Background

DO

  • Degree + college
  • Year of passing
  • CGPA if 7.5 or above
  • 2 relevant subjects

DON'T

  • 10th / 12th marks
  • Every subject
  • Backlogs
Say: “B.Tech in CS from XYZ College, 2025, CGPA 8.2.” Keep it short.
Block 4

Internship

Company, role, and one clear result.

The Line

At [Company] as [role], I [result].
  • ✅ “At Infosys, I built 6 REST APIs.”

DON'T

  • Daily task list
  • Complaints
  • “Just training”
  • Fake work
Block 4b

Projects

Two explained clearly is better than many listed.

The Line

Built [what] using [tech] that [result].
  • ✅ “React expense tracker, 50+ users.”
  • Mention live link or GitHub

DON'T

  • Full architecture
  • Tutorial clones only
  • Long project list
Block 4c

Any Real Experience Counts

Freelance

  • Client work
  • What you built

College Team

  • Club role
  • Team size

Tutoring

  • Shows clarity
  • Soft skills
Never fake. One honest project beats a fake internship.
Block 5

Skills & Certifications

DO

  • 3–4 relevant skills
  • Match the job description
  • One certification
  • Say what you can build

DON'T

  • “I know everything”
  • 20 skills at once
  • MS Word / typing speed
  • Bluffing
Test: can you build one thing with each skill? Then list it.
Block 6

Achievements

Numbers make you memorable.

Pick

  • Hackathon
  • Scholarship
  • Open source
  • Published paper

DON'T

  • School prizes
  • Attendance certificates
  • Anything you can't explain
Block 6b

Hobbies

Pick ones that show a trait.

Discipline

  • Sport / gym

Creativity

  • Blog / design

Teamwork

  • Clubs / volunteering
Keep it short: “I play badminton and write tech blogs.”
Block 7

Career Goal

DO

  • 3-year goal
  • Tie it to this role
  • Be confident

DON'T

  • “Go abroad”
  • “Own company”
  • “Learn everything”
  • “Anything you give”
